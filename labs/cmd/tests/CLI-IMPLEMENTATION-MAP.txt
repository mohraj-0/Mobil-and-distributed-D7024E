   Reads the private signing key and package bytes. Without --force, checks

   Stores the blob, signs/stores a version record, then signs/publishes a latest
   pointer. Prints individual replica acceptance/rejection results.
   Blob storage: labs/registry/registry.go:86 - StoreBlob()
   Version-record storage: labs/registry/registry.go:96 - StoreVersionRecord()
   Signing: labs/metadata/records.go:71 - SignVersionRecord()
            labs/metadata/records.go:117 - SignLatestPointer()
   Normal publication: labs/kademlia/latest.go:252 - PublishLatest()
   Forced publication: labs/kademlia/latest.go:258 - PublishLatestForced()

   --prev
   Handled inside publish(). Chooses a predecessor by published version.
   0 means genesis. With --force, a 64-character record hash is also accepted.
   Without --prev, the current latest record is selected automatically.

   --force
   Handled inside publish(). Bypasses publisher ownership/history preflight
   and the normal authenticated version-record storage path so invalid updates
   can be attempted. It does not bypass parsing, signing or receiver validation.

   Receiver validation (the security checks behind publication):
     labs/kademlia/latest.go:33 - verifyLatest()
       Validates pointer/key binding, ownership, referenced history and version.
     labs/kademlia/latest.go:95 - acceptLatest()
       Authenticates the proposed pointer before committing it.
     labs/kademlia/latest.go:107 - commitLatest()
       Locks the package and rejects rollback, same-version replacement and
       histories not containing the current accepted record. Exact replay is
       accepted without changing the head.
     labs/kademlia/latest.go:139 - handleLatestRPC()
       Receives UPDATE_LATEST and sends acceptance/rejection back to the sender.
     labs/metadata/history.go:50 - TraverseHistory()
       Checks hashes/signatures, package identity, predecessor links, strictly
       increasing versions and cycle/traversal guards.
